## Fair Use Terms

Each license allows up to **100,000 API requests per month** under fair-use terms. This is a usage guideline, not a hard technical cap. Usage significantly above this limit may result in license review.

## How Licenses Work

**One license key per email address.** Each purchase generates one license key, tied to the payment email address on file.

**Keys are delivered base64-encoded.** Your license key arrives in your payment email encoded in base64. You must decode it before use. See [Authentication](/proximos-api/authentication) for instructions.

**Lost your key?** Request a re-send from the [Proximos API website](https://enlazosystems.com/proximos-api/purchase). It will be resent automatically to your original payment email address.
