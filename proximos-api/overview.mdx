The Proximos API is a simple, read-only HTTP GET API that gives you programmatic access to the **complete history of macOS releases** — from Classic Mac System 0.97 on the original Mac 128k all the way to the latest macOS releases today.

Use it to build custom private workflows around macOS release dates, version history, and compatible hardware identifiers (board IDs).

## What you can look up

- **The latest release** for any macOS major version number
- **The latest update available** for a specific Mac model (board ID) on a given major version
- **The next available update** from a specific version — the _version proximo_
- **All compatible board IDs** for a given macOS version
- **All supported macOS versions** for a specific board ID

## Base URL

All requests are HTTPS GET requests to:

```text
https://proximosapi.enlazosystems.com
```

  <Card title="Legacy Mac OS X" icon="display">
    **Mac OS X 10.0 Cheetah – OS X 10.15 Catalina**

    Intel Macs (10.6–10.15) use Apple's internal board ID strings (e.g. `Mac-F4208EAA`, `Mac-35C5E08120C7EEAF`). PowerPC Macs (10.0–10.5) use Apple model numbers — the same identifiers printed on the machine. Examples: `M5183` (Power Mac G3 B&W \+ G4 PCI/AGP/Gigabit/DA), `A1047` (Power Mac G5), `M6498` (iMac G4), `A1103` (Mac mini G4).
  </Card>

  <Card title="Classic Mac OS & System" icon="desktop">
    **System 0.97 – Mac OS 9.2.2**

    Board IDs are the Apple model number physically printed on the machine, verified against EveryMac.com. Examples: `M0001` (Mac 128K), `M5521` (iMac G3 350–700 MHz), `M7777` (all PowerBook Duo models), `M1688` (Power Mac 8100). Where Apple assigned one model number to multiple machines, the union OS range applies.
  </Card>
